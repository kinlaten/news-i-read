## AI Security and Vulnerabilities

- Google Deepmind researchers have published a framework, "AI Agent Traps," detailing how malicious web content can weaponize autonomous AI agents. They identified six categories of traps, with some achieving an 86% success rate in content injection. Recommendations include adversarial training, runtime content scanners, and new web standards. [Ground.news](https://ground.news/article/google-deepmind-researchers-warn-hackers-can-hijack-ai-agents-through-malicious-web-content)
- The same Deepmind findings indicate that behavioral control traps targeting Microsoft M365 Copilot achieved 10/10 data exfiltration in tests. [Bitcoin News](https://bitcoinethereumnews.com/bitcoin/deepminds-ai-agent-traps-paper-maps-how-hackers-could-weaponize-ai-agents-against-users-bitcoin-news/)
- Anthropic confirmed an accidental release of over 500,000 lines of source code for its AI coding assistant, Claude Code, due to an npm packaging error. Despite Anthropic blocking services in China, the leaked code has been reposted on GitHub. [Cybernoz](https://cybernoz.com/claude-code-source-leaked-via-npm-packaging-error-anthropic-confirms/)
- The leak of Claude Code's source code has raised significant concerns, with reports suggesting Anthropic is attempting to downplay the incident. [The Register](https://www.theregister.com/2026/04/06/anthropic_code_leak_kettle_podcast/)
- Another report on the Claude Code leak highlights that Chinese developers have been quick to repost the code on GitHub. [NewsBytesApp](https://www.newsbytesapp.com/news/science/anthropic-accidentally-leaked-over-500000-lines-of-claude-code/tldr)
