# Tech News - April 30, 2026

A day marked by significant security vulnerabilities in both Google's AI tools and the Linux kernel, alongside a notable billing error from Anthropic.

## Cybersecurity Vulnerabilities

- Google has addressed critical security flaws in its Gemini CLI and Cursor, including a CVSS 10 rated RCE vulnerability, to prevent code execution. [The Hacker News](https://thehackernews.com/2026/04/google-fixes-cvss-10-gemini-cli-ci-rce.html)
- A nine-year-old Linux kernel flaw, dubbed "Copy Fail" (CVE-2026-31431), has been disclosed, allowing for reliable local privilege escalation and root access on most Linux distributions released since 2017. Patches are now available. [Help Net Security](https://www.helpnetsecurity.com/2026/04/30/copyfail-linux-lpe-vulnerability-cve-2026-31431/), [The Register](https://www.theregister.com/2026/04/30/linux_cryptographic_code_flaw/), [heise online](https://www.heise.de/en/news/Copy-Fail-Linux-root-in-all-major-distributions-with-732-bytes-of-Python-11277657.html)

## AI Service Billing Issue

- Anthropic users experienced a billing bug where a specific filename ("HERMES.md") in Git commit history bypassed subscription limits, leading to unexpected charges. Refunds were reportedly denied. [byteiota](https://byteiota.com/anthropics-hermes-md-billing-bug-200-overcharge-refund-denied/)
