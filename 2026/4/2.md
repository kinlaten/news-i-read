# Tech News - April 02, 2026

A significant source code leak from Anthropic's AI assistant Claude dominated tech news, alongside discussions on a new C++ backend for OCaml and ongoing cybersecurity threats.

## Anthropic's Claude Code Leaked

*   Anthropic's flagship coding assistant product, Claude Code, suffered a major source code leak. The breach involved approximately 512,000 lines of code, primarily due to a misconfigured npm package that included debug files. This error allowed the entire source code to become publicly accessible. [Helixar.ai](https://helixar.ai/press/anthropic-claude-code-source-leak-npm-source-map/)
*   The leak, described as "human error," has spread rapidly across the internet, leading to chaos and the takedown of over 8,000 GitHub repositories. [Pakistan Today](https://www.pakistantoday.com.pk/2026/04/02/anthropics-code-leak-goes-viral-sparks-chaos-with-8000-github-repos-taken-down)
*   The incident is being viewed by some, like Cory Doctorow, as potentially beneficial, arguing that the leak of Claude's source code, especially a coding assistant, is a positive development. [Pluralistic](https://pluralistic.net/2026/04/02/limited-monopoly/)
*   Details of the leak and its timeline are being documented, highlighting the accidental exposure of Anthropic's "crown jewels." [Hari Krishna Substack](https://nandigamharikrishna.substack.com/p/the-claude-code-leak-how-512000-lines)
*   The exposure of Anthropic's AI Agent Claude source code has raised concerns about commercially sensitive information being made public. [The Times of India](https://timesofindia.indiatimes.com/technology/tech-news/anthropics-ai-agent-claude-leak-that-it-termed-human-error-has-exposed-commercially-/articleshow/129963827.cms)
